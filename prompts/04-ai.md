1. 题目解析
2. AI 出题

# 4. Explain Question

实现：

```http
POST /api/v1/ai/explain
```

request：

```json
{
  "question_id": "...",
  "user_answer": "A"
}
```

response：

```json
{
  "correct": false,
  "explanation": "...",
  "key_point": "...",
  "common_mistake": "..."
}
```

AI 不负责最终 correctness。

Backend 必须先确定：

```text
correct = answer == expected_answer
```

---

# 5. Generate Question

实现：

```http
POST /api/v1/ai/generate-question
```

request：

```json
{
  "knowledge_point_id": "...",
  "difficulty": 2
}
```

AI output：

```json
{
  "content": "...",
  "options": [
    {
      "key": "A",
      "content": "..."
    },
    {
      "key": "B",
      "content": "..."
    },
    {
      "key": "C",
      "content": "..."
    },
    {
      "key": "D",
      "content": "..."
    }
  ],
  "answer": "B",
  "explanation": "...",
  "difficulty": 2
}
```

Backend 必须：

1. validate
2. verify knowledge point
3. verify 4 options
4. verify answer exists
5. verify difficulty
6. save question
7. save options
8. save question ↔ knowledge point relation

---

# 6. Structured Output

禁止依赖字符串解析。

优先使用 provider SDK 的 structured output / JSON schema 能力。

最终必须通过：

```text
Pydantic
```

验证。

---

# 7. Prompt

题目生成 Prompt 要求：

* 单选题
* 四个选项
* 只有一个正确答案
* 干扰项合理
* 明确考察指定知识点
* 不能依赖外部信息
* 解析清晰
* 难度符合要求
* 不生成重复题目

---

# 8. Error Handling

LLM：

* timeout
* invalid JSON
* rate limit
* provider error

必须转换为应用层错误。

不能把 SDK exception 直接暴露给客户端。

---

# 9. Tests

测试：

* explanation
